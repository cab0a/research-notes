# STEP Revision Controls — v1.7.0

穴径・位置・板厚・増減・曖昧な対応などを調べる自作16組と、既存の外部公開STEP6件を固定しました。自作32ファイルは作成条件と正解値を記録し、別々にSTEP出力しています。外部6件は同じファイルを両側に渡す読込条件の確認用で、実際の設計変更ペアではありません。出所・ライセンス・SHA-256を記録し、許容差や判定ルールはv1.5から変更していません。詳細は英語本文に示します。

## English Summary

This fixed corpus contains 16 authored revision controls and all six previously
frozen external STEP files. Authored pairs are built independently of the matching
engine, with analytic dimensions and explicit expected abstention. External
self-pairs test intake coverage only; they are not manufacturer revisions.
The manifest pins every byte sequence and records provenance, license references,
recipes and expected outcomes. Normal evaluation is offline and checks digests
before native geometry. No thresholds were fitted to this corpus. These controls
are neither a representative industrial benchmark nor an independent learning set.

## Files and rights

- [Manifest](manifest.json): 22 cases, 38 unique STEP paths, analytic truth and hashes.
- `sources/`: 32 authored STEP files, generated by Inefficiency Lab using
  [this independent constructor](../../experiments/build_revision_fixtures.py).
  These use the repository's [PolyForm Noncommercial 1.0.0 license](../../LICENSE).
- [External source catalog](../public-step-corpus/README.md): CadQuery (Apache-2.0),
  build123d (Apache-2.0 and NOTICE), and u-blox (retained explicit permission).
  Original source bytes, full upstream commit IDs, URLs, retrieval date,
  attribution, license originals and notices are retained in that sibling corpus.
  Their terms apply independently of the authored files' license.
- No external file is modified or rebranded as our authored model. The two SAM
  encodings represent one part family; six files are five external shape families.
- Derivatives and redistributed copies must retain their matching notices.

## Evaluate the committed bytes

From the research repository root, with Python 3.12:

```bash
python -m pip install -e ".[geometry,test]"
python -m research_notes.revision_benchmark --output-dir output/revision-check --repeats 3
```

The CLI compares first and consults truth only for evaluation afterwards. A digest
mismatch aborts before native import. A contract mismatch produces a nonzero exit.
The JSON and CSV retain all cases, including intake rejection and abstention;
HTML reports exist only for pairs that both imported successfully.

Explicit fixture regeneration (not needed for evaluation):

```bash
python experiments/build_revision_fixtures.py
```

The independent fixture builder uses OCCT boxes/cylinders/Boolean operations;
the same OCCT runtime also reads STEP. Different CAD products and kernels have
not been established as equivalent by these controls. Small-coordinate values
are rounded by the current descriptor to nine decimals; a recorded zero error
is not proof of exact arithmetic.

See [measured results and limits](../../notes/step-revision-benchmark.md).
