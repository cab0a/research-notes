# Public STEP Corpus

## 日本語概要

3つの公開元から6つのSTEPを収録しました。取得日、固定コミット、元URL、SHA-256、帰属、ライセンス原文を記録しています。STEPとライセンスのバイト列は無変更です。SAMのAP203/AP214は同じ部品の比較用ペアで、独立した形状は5系列です。詳細は英語本文に示します。

## English Summary

These are external validation inputs, excluded from training and calibration.
They are not generated by this repository. Local filenames differ from upstream;
the bytes, including original headers, remain unchanged. All were retrieved on
2026-09-28. The manifest records full commits, URLs, sizes and SHA-256 digests.
The repository-level Apache licenses and build123d NOTICE are retained verbatim;
u-blox's upstream README (saved here as LICENSE.txt) contains its explicit use/copy/modify/distribute permission.
External assets retain these upstream terms, independently of this project's
PolyForm Noncommercial license. No upstream endorsement is implied.

The selection favors small redistributable files with different geometry,
source units, root counts and AP declarations. It is a curated six-file corpus,
not a random or representative industrial benchmark. The six selected files
remain included even when operations are unsupported or checks disagree.

- [Manifest](manifest.json): provenance, digests, selection reasons and license scope.
- [Frozen observations](expectations.json): reviewed regression outcomes, not geometric ground truth supplied by the authors.
- [Terminal demo](demo_commands.txt): inspect and export the 42-face bracket.
- [Full study](../../notes/public-step-corpus.md): method, failures and scope.

From the repository root, run offline:

```bash
python experiments/run_public_step_corpus.py
```

To explicitly reacquire the fixed assets into a separate directory:

```bash
python experiments/fetch_public_step_samples.py --destination output/public-step-download
python experiments/run_public_step_corpus.py --corpus-dir output/public-step-download --output-dir output/public-step-recheck
```

Changed downloads or existing bytes are refused. Normal tests and CI never fetch.
`.gitattributes` disables line-ending conversion for raw assets and licenses.
Generated previews use diagnostic face colors; the original colors are not
reproduced. Geometry-only STEP exports are generated derivatives and do not
preserve source colors, names, product hierarchy, materials, PMI or constraints.
Keep the matching upstream attribution and license with redistributed derivatives.
