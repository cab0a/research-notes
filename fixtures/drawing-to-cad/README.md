# Authored three-view drawing controls

2026-10-22にこのリポジトリの研究用に作成した合成入力。
外部図面・ベンチマークのデータ・重み・コードは含めない。
本リポジトリの[ライセンス](../../LICENSING.md)に従う。

- `inputs/`: 復元処理が読む可視SVGと人が与えるcontext JSON。
- `evaluation/`: 評価側だけが読む設計値、解析式の値、正解STEP。
- `manifest.json`: 入力SHA-256、ファミリーID、期待状態/理由、評価用キー。
- 生成元: [build_drawing_cad_fixtures.py](../../experiments/build_drawing_cad_fixtures.py)。

contextはmm、第一角法/第三角法、3ビューのグループ対応と、
「矩形板にZ方向の分離した円形貫通穴」という事前仮定だけを与える。
数値寸法はSVGの可視テキストにのみ置く。幅W、奥行L、厚さT、穴XY/径/THRUを読む
専用文法であり、一般の製図注記の認識ではない。
SVGに隠したCADパラメータやSTEPへの参照を入れていない。

原点は板の(0,0,0)。正面(+X,+Z)、平面(+X,+Y)、右側面(+Y,+Z)。
第三角法は平面を上・右側面を右、第一角法は下・左に置く。
板は40×30×8 mm、無孔/1穴/2穴の3ファミリー。
1穴は(12,10), φ6、2穴は(10,8), φ4と(28,21), φ6。
穴は全て板厚を貫通する。2穴の注記順は幾何順と意図的に逆にしている。

正常6入力には第一角法/第三角法と縮尺の変更が含まれる。
7つの負例は厚さ不足、幅矛盾、投影法誤指定、ビュー対応逆転、
貫通/止まりの曖昧さ、隠れ線欠落、未対応輪郭である。
同じファミリーの派生入力は独立した部品ではない。
これらは処理の開発にも使った対照群であり、未知の実務図面への性能は示さない。

正解STEPは復元処理を呼ばず、直接OCCT MakeBox/MakeCylinder/Booleanで作る。
体積は`W L T − Σπr²T`、表面積は
`2(WL+WT+LT) − 2Σπr² + Σ2πrT`。
分離した貫通穴という条件でのみ使う。
解析値・生成元設計値・実際のSTEPの観測値を評価時に区別する。
正解と候補は同じOCCT由来なので、異なる実装/カーネルによる独立評価ではない。

通常の追試では生成スクリプトを実行せず、この固定入力を読む。
STEPの再生成はヘッダーを変えうるため、新しいハッシュを同じ固定物と呼ばない。
手順は[再現ガイド](../../docs/drawing-to-cad-reproduction.md)、
結果は[研究ノート](../../notes/drawing-to-parametric-cad.md)を参照。
