# Dimension-line reconstruction controls

このリポジトリで2026-10-22に作成した合成図面。外部のCAD図面や規格図版の複製ではない。
[本リポジトリのライセンス](../../LICENSING.md)に従う。
生成元は[build_drawing_dimension_fixtures.py](../../experiments/build_drawing_dimension_fixtures.py)。

`inputs/`は三面図のSVGと人のcontext。可視の数値、矢印、寸法線、補助線、
直線の径引出線を含み、専用の`W=`/`X=`等、寸法ごとの型属性、正解参照を含まない。
contextは投影法・単位・ビューのグループ対応・部品ファミリーだけ。
尺度や数値寸法はcontextへ渡さない。原点は板の(0,0,0)という実験上の約束。

対象は幅40/奥行30/厚さ8 mmの無孔・1穴・2穴板と、小数寸法の板。
1穴は(12,10), 径6 mm。2穴は(10,8), 径4と(28,21), 径6 mm。
小数板は52.5×37.25×6.5 mm、穴(17.5,13.25), 径5.5 mm。
穴はZ方向に貫通。第一角法は平面を下・右側面を左、第三角法は上・右に配置。
正面(+X,+Z)、平面(+X,+Y)、右側面(+Y,+Z)を用いる。

復元対象8入力、保留対象12入力。
縮尺・ID・描画順・矢印の頂点順の派生は、独立した部品ではない。
開発にも使った合成対照で、未知ファミリーの評価ではない。
表記は水平/垂直の直線寸法と水平数値テキストに絞り、ISO/JISの全表記への適合は検証しない。

`evaluation/`の設計値・解析式・正解STEPは評価側だけが読む。
正解は前回の独立した直接OCCT生成処理を再利用し、今回の寸法線パーサーを呼ばない。
体積/面積の解析式も利用するが、正解と候補が同じOCCT由来である限界は残る。
manifestで固定入力と正解への対応、期待状態/理由、SHA-256を管理する。

通常の追試では固定入力を読み、生成スクリプトを再実行しない。
