# 既存の認識・照会を最小構成で接続する — v1.17.0

実施日：2026-10-19。**既存STEP経路の観測値を、業務定義の17項目へ出所付きで接続した。** 基準測定の記録とは部品ID・入力ハッシュで照合する。業務への適用可否・帳票への実転記・省力化はまだ判定しない。

## 選んだ構成

現在の`hole_inventory.analyze_step`を検査用読込・丸穴＋長孔・プレビューなしで一度呼び出し、その結果を接続する薄い処理を追加した。既存の認識を組み直したり、独自の認識結果を追加したりはしない。既存のOCCT/Python環境以外の依存も追加していない。

[前回のB-Rep調査](brep-native-recognition-strategy.md)を利用候補の整理として維持する。今回の業務定義へ現在の経路を接続するのに、SMLibへの移植や3基盤の共通化は必要なかった。SMLib/SolidCraft/ClassCADのネイティブ形式をこの版で入力できるという意味ではない。

## 取得して引き渡すもの

| 内容 | 接続と出所 |
| --- | --- |
| 入力 | バイト列のSHA-256・容量・表示用ファイル名。名前から品番を推測しない |
| 入力の特徴 | ソリッド/面/辺数、境界、許容差、単位コンテキスト・mm変換倍率等の既存観測。未取得を不明として保持 |
| 実行条件 | API名、既存認識版1.14.0、固定オプション、Python/OS/パッケージ/OCP、選択した実装6ファイルのハッシュ |
| 集計5項目 | 明示した部品参照、入力SHA-256、全体穴数、認識行数、全体数の状態 |
| 特徴ごとの12項目 | 種類、径/幅/全長、位置、内部方向/長手方向、深さ/貫通長、特徴ID、ソリッド/面参照等 |
| 値の出所 | 保存した既存JSON内への参照。コピー、XYZの組立て、単一ソリッド番号の導出を区別 |
| 保留の説明 | 既存のreview_itemsと条件・元メッセージを結果内に維持 |
| 基準記録との関係 | 同じ定義・入力SHA-256・計画した部品ID・抽出側の方法であることを照合。元記録は変更しない |

丸穴の幅や長孔の丸穴径は非該当、全体数の保留は不明、指定しない部品参照は未提供とする。値の有無を「自動確定して業務に使える」という判断へ変換しない。複数ソリッドを取得しても単体業務の適合とはせず、v1.18の判定対象として残す。

全体数の不明を認識行数で埋めない。旧来の板解析に所属番号がない場合は、測定されたソリッド数が1のときだけ番号1を導出して根拠を付ける。多ソリッドで所属が欠ければ不明とする。元CADの品番・材質・公差・加工方向なども追加推定しない。

## 検証方法と結果

[固定した10入力](../fixtures/cad-workflow-extraction/manifest.json)を各2回実行した。全10入力で、呼出時間を除いた観測内容が繰返しで一致し、各項目の参照先を同じ出力JSON内で辿れた。

| 検証 | 結果と範囲 |
| --- | --- |
| 既存7入力の回帰 | 元の穴一覧JSONはv1.15の固定結果と一致。認識器の条件・値を変更していない |
| 状態の維持 | complete 4、partial 2、unresolved 2、rejected 2。未解析・0行を0穴としない |
| 項目の出所 | 全10入力で242セルを確認。不明・未提供・非該当を含む接続項目数で、242個の独立した寸法や形状ではない |
| 公開ブラケット | 丸穴5・長孔6の計11行。全体数は不明のまま、長孔の幅4.5/全長7.5/貫通長3 mm等を元の値に接続 |
| 楕円の入力 | 0行・unresolvedを維持。穴なしと認定しない |
| 公開組立例 | 2ソリッドと元単位からの倍率1000を保持し、出力単位mmを再変換しない。単体業務の適合は未評価 |
| 単位欠落・非STEP | 読込拒否と不明の座標・形状を維持 |
| 基準記録への接続 | 部品ID・入力/定義ハッシュを照合し、機械の抽出時間を人の作業や品質確認として書き込まない |

認識対象の精度を新しく評価したセットではない。合成板の変形例を別の未見部品系列として扱わず、公開ブラケットの11行を全穴の正解にしない。既存形状から取得された値は幾何寸法で、元CADの公称寸法や製造公差ではない。

CLI/Python、出力と入力の衝突、誤った基準記録への接続、出所の参照切れ、行数・径と幅・所属・単位方向等の不整合をテストした。[結果](../results/cad-workflow-extraction/results.json)・[再現方法](../results/cad-workflow-extraction/README.md)・[テスト/配布記録](../results/cad-workflow-extraction/verification.json)を参照。

## 到達点と残ること

v1.15の定義、v1.16の計測記録、現在のSTEP抽出を、同じ入力と出所で照合できるようになった。パッケージ/画面はv1.17.0。既存の穴一覧JSON/CSV・認識条件、定義チェッカー、計測記録の版と過去の証拠は維持した。

`contract_conformance`・`business_completion`・`adoption_decision`は`not_evaluated`を返す。工程別の利用者実測や実帳票は未提供で、v1.16の現場測定待ちは解消していない。少量サンプルによる予測、新規性、中小企業向けの優位も未実証である。

次のv1.18では、これらの観測を必要項目・単体等の業務条件に対応付け、取得可能・要確認・情報不足の理由を説明する。v1.19相当の帳票出力や、採否判断を今回実装したとはしない。[操作ガイド](../docs/cad-workflow-extraction.md)と[計画](sme-cad-automation-roadmap.md)を参照。
