# 形状特徴候補の認識結果

## この調査で確認したこと

境界表現で構成された立体について、個々の面の種類、向き、曲率、輪郭線、共有辺、隣接面の組み合わせから、穴、段差、溝、面取り状、丸み状の形状特徴候補を規則的に抽出できるかを確認しました。

評価には業務データや外部の設計データを使わず、形状と正解寸法を独立に定められる九つの合成立体だけを使用しています。各形状は構築直後と標準交換形式で保存して再読込した後の二段階で評価しました。

## 各候補をどのように認識したか

### 穴

一周分の円筒面を探し、円筒面の向きを調べます。面の法線が円筒軸へ向かう場合は材料の内側にある空洞候補とし、軸から外へ向かう場合は円筒突起として穴候補から除外します。

止まり穴では、円筒面に隣接する円形の底面も同じ候補へ含めます。貫通穴には底面がないため、この違いで貫通穴と止まり穴を分けます。

### 段差

高さの異なる二つの平行な水平面と、その両方に隣接する一つの垂直な立ち上がり面を一組として扱います。二つの水平面の距離から高さを求め、立ち上がり面の面積と高さから幅を復元します。

### 溝

内向きで半径が等しい二つの部分円筒面と、それらをつなぐ二つの平面を一つの隣接部分構造として扱います。円筒半径、二つの軸の距離、側面積から、幅、全長、深さを復元します。

### 面取り状

二つの座標軸方向に同じ大きさの法線成分を持つ斜面を探します。その斜面が、互いに平行ではない二つの親平面と実際に共有辺を持つことを要求します。

押し出し方向の端面は斜面に隣接していても、面取りがつなぐ二つの親面ではありません。単純に面番号の小さい隣接面を二つ選ぶと誤った証拠になるため、面の法線と共有辺の両方を使って除外しました。

### 丸み状

一周に満たない一定半径の曲面を探し、その曲面が二つの親平面を共有辺でつないでいることを確認します。曲面の半径、面積、最長境界辺から、半径、長さ、角度を復元します。

丸みの軸方向にある端面は親面に含めません。二つの親平面は互いに平行ではないことも確認します。

## 面取りではなく面取り状と呼ぶ理由

面取り操作で作った斜面と、輪郭から直接作った斜面を独立に比較しました。

| 比較項目 | 面取り操作 | 直接作成 |
| --- | ---: | ---: |
| 頂点 | 十個 | 十個 |
| 辺 | 十五本 | 十五本 |
| 面 | 七枚 | 七枚 |
| 殻 | 一個 | 一個 |
| 立体 | 一個 | 一個 |
| 体積 | 五百七十二 | 五百七十二 |
| 一方から他方を引いた差分体積 | 零 | 零 |
| 逆方向に引いた差分体積 | 零 | 零 |

最終的な境界形状は同じであり、どちらも同じ面取り状候補として認識されました。しかし、最終形状だけから、設計者が面取り操作を使ったのか、輪郭を直接作ったのかは判断できません。

したがって、この認識器が根拠を持って言えるのは「面取りに似た境界形状がある」までです。「面取り操作で作られた」「この加工方法で製造する」といった設計履歴や製造意図は証明できません。

## この結果から分かること

- 曲面の種類だけでは穴と円筒突起を区別できず、面の向きと材料側の情報が必要です。
- 一つの面だけでなく、複数の面と共有辺からなる隣接部分構造を一つの特徴候補として扱う必要があります。
- 面番号の順番は意味的な証拠にならないため、法線、曲率、共有辺、隣接関係を明示的に確認する必要があります。
- 標準交換形式での再読込後も、この九つの統制形状では候補の種類と寸法を再現できました。
- 最終境界が同じ場合、形状だけから作成履歴や設計意図を復元することはできません。

## 現在の限界

- 各特徴は孤立しており、穴と溝、面取りと丸みなどが互いに干渉する形状は評価していません。
- 形状は座標軸に沿った固定寸法の合成立体です。
- 皿穴、段付き穴、円すい穴、ねじ、ポケット、島、リブ、抜き勾配、切り下げ、可変半径の丸みは未評価です。
- 面取りは対称な四十五度の一条件、丸みは一定半径の九十度の一条件に限定しています。
- 曲率は代表位置で評価しており、面全体の連続性を証明するものではありません。
- 工具の接近可能性、素材形状、加工順序、製造可能性は評価していません。
- 一種類の形状計算核と標準交換形式の読込経路だけを使用しています。
- 実際の業務用設計データや製品データでは評価していません。

## 次に確認したい疑問

一つ目は、複数の特徴候補が重なる場合に、候補を無理に一つへ決めず、どのように併記すべきかです。

二つ目は、一般的な向き、寸法、公差、円すい面、自由曲面を含む場合にも、同じ規則が成立するかです。

三つ目は、面上の一点だけでなく共有辺に沿って法線と曲率を評価し、接線連続性や凹凸をより確実に判定する方法です。

四つ目は、将来の学習型認識器へ面と隣接関係を入力する場合に、根拠、出典、棄権判断をどのように保持するかです。
